# Analytics Portfolio

My work from the data analyst training course.

## Getting the data

The data is not stored in this repository. To get it:

1. Download the "Brazilian E-Commerce Public Dataset by Olist" from https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce
2. Unzip it.
3. Put the 9 CSV files in the folder `data/raw/olist/`.

## Setting up Python

1. Install uv from https://docs.astral.sh/uv/
2. In this folder, run `uv venv`, then activate it.
3. Run `uv pip install ipykernel`.
